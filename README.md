# Gamer Overlay

A lightweight, zero-latency keystroke and mouse overlay built for streamers and competitive gamers. 
It runs entirely in the background, uses almost zero PC resources.

## Features
* **Fully Customizable:** Add or remove Numpad, Arrows, Modifiers, or strip it down to just your mouse clicks.
* **Stream Ready:** Transparent background, ready to be captured directly into OBS.
* **Smooth Animations:** Buttery smooth fade-in and fade-out animations when pressing keys.
* **Live CPS Tracker:** Built-in Clicks-Per-Second counter.
* **Game Profiles:** Save your favorite colors and layouts to specific profiles (FPS, MOBA, MMO).

## How to Download & Run
1. Go to the **[Releases](../../releases)** tab on the right side of this page.
2. Download and extract zip file.
3. Double-click the **`Overlay.exe`** to run it. *(No installation required!)*

## How to Use
* **Unlock & Move:** Press **`Ctrl + Shift + O`** while in-game to unlock the overlay. Click and drag the box to move it anywhere on your screen. Press the hotkey again to lock it in place.
* **Settings Menu:** The app hides cleanly in your Windows System Tray (the little arrow next to your clock in the bottom right). **Right-click** the keyboard icon to open the Settings Menu or exit the app.

## How to add to OBS
1. Add a new **Window Capture** source.
2. Select `[Overlay.exe]: Overlay`.
3. Set the Capture Method to **Windows 10 (1903 and up)**.
4. Check the **Allow Transparency** box.
